## Goal

Convert imported SMS messages into structured financial events.

Status: Completed (`regex-financial` → `sms_analysis` → `financial_events`, then optional Firefly push).

## Supported Event Types

- financial.expense
- financial.income
- financial.bill
- financial.credit_card_due

## Examples

Input SMS:

"Rs. 4532 spent on HDFC Credit Card at AMAZON"

Output Event:

{
  "type": "financial.expense",
  "merchant": "Amazon",
  "amount": 4532
}

## Scope

- Amount extraction
- Merchant extraction
- Bank identification
- Event type classification
- Persist normalized financial events

## Acceptance Criteria

- Financial SMS messages are detected
- Structured events are created
- Unknown SMS messages are ignored
- Works completely offline

## Non Goals

- AI classification
- LLMs
- Embeddings
- RAG
