# Attention layer (not a Firefly clone)

Status: In progress (tasks 1–4 done)

## Goal

Expose what Dhan does not: due SMS, push exceptions, and a mixed timeline. Posted ledger stays in Firefly III.

Dhan owns: transactions, balances, charts, budgets. Narada owns: SMS truth, classify/skip reasons, bills that never post, blocked/unpushed rows, homelab events.

## Task order

1. **Due feed** — done. `GET /knowledge?kind=due` from `sms_analysis` where subcategory `bill` and cashFlow `NEUTRAL`. Payload includes due date, min/total due, last4 when present. Payment acks are excluded. These rows never enter `financial_events`.
2. **Push exceptions** — done. `GET /knowledge?kind=exception` dry-runs unpushed `financial_events` against Dhan. Payload `status` is `blocked` or `skipped` plus the same reason as `sms:firefly-map`. Filter `status=blocked|skipped`. Needs Firefly env (`503` if missing). Ready-but-unpushed rows are not exceptions.
3. **`GET /timeline`** — done. Chronological mix of due items, push exceptions, and `narada_events`. Envelope `{ type, id, occurredAt, payload }`. Filters: `from`, `to`, `type` (`due` | `exception` | `event` | `financial`). Default types omit posted financial (Dhan remains the ledger). Firefly missing → exceptions omitted, dues + infra still return. Each stream capped at 500 newest in-window.
4. **Telegram** — done. After SMS ingest, new dues and Firefly `blocked` rows (not skipped openings). First scan seeds; later scans Telegram new dues, newly blocked, and still-blocked once (second consecutive scan). No spend summaries.
5. **Dashboard (later)** — Home = attention only (dues, exceptions, service strip, last import). No Money charts, net worth, or budgets.
6. **`GET /knowledge/search`** — merchant/body text after timeline exists.
7. **Housekeeping** — close GitHub issues that are already shipped (`#32`–`#38` SMS ingest/classifier/folder watcher).

## Out of scope

- Firefly-style transaction list, reports, or account screens
- RAG, vector DB, AI extraction
- Bank statement importer
- Paperless / Gmail / calendar
- API keys

## Acceptance

- Due reminders are queryable without opening Dhan — `GET /knowledge?kind=due`
- A blocked push is visible over HTTP, not only `sms:firefly-map` stdout — `GET /knowledge?kind=exception`
- Timeline is useful with Dhan closed (dues + infra + exceptions) — `GET /timeline`
- New dues / repeated blocked pushes Telegram after SMS ingest (first scan silent)
- No new UI that duplicates Firefly transaction views
